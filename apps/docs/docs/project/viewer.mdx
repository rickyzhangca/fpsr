:::note
The viewer is a product in this monorepo (`@fpsr/viewer`). It is not required to use the npm library.
:::

The viewer is a React app for pasting, inspecting, previewing, and exporting Factorio blueprint strings. It consumes the workspace `fpsr` package and private CDN assets.

**Live demo:** [https://fpsr.fprints.xyz](https://fpsr.fprints.xyz)

Local development from the monorepo root:

```bash
pnpm dev
# or: vp dev apps/viewer
```

Docs for the library live under [Guide](/guide); this site is [fpsr-docs.fprints.xyz](https://fpsr-docs.fprints.xyz).
