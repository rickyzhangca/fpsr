---
title: Install
description: Add fpsr to a browser or Node.js project.
---

Install the library from npm:

```bash
npm install @rickyzhangca/fpsr
```

```bash
pnpm add @rickyzhangca/fpsr
```

```bash
yarn add @rickyzhangca/fpsr
```

For Node.js rendering, add the optional peer dependency:

```bash
npm install skia-canvas
```

:::note
The npm package ships **code only**. Sprite atlases and the render database are generated from your own Factorio install and loaded separately — see [Quick start](/quickstart).
:::
